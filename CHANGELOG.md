## [0.1.0] - 2026-08-12

### Added

- React 19.2 provider, inline text transformer, and low-level emote image
  component.
- Controlled, preloaded, and remotely fetched 7TV emote sets.
- Plain, delimited, case-insensitive, and fully custom matching syntaxes.
- Animated WebP, AVIF, GIF, PNG, responsive CDN variants, and static fallbacks.
- SSR support and a React Server Components-safe `/core` entrypoint.
- ESM, CommonJS, and TypeScript declaration builds.
- Strict type, lint, unit, integration, and package-consumption checks.
